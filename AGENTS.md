# Рабочие правила репозитория

## Локальный запуск

- Основной способ запуска — `make run` из корня репозитория.
- Корневой `docker-compose.yml` описывает единый локальный Compose-проект.
- Для обычного запуска не используйте вложенный Compose-файл `backend/python/users-state/docker-compose.yml`.
- Полезные команды: `make status`, `make stop`, `make seed-demo`.

## Демоданные

- `make seed-demo` намеренно пересоздаёт локальные индексы OpenSearch: `jira`, `git`, `gitlab`, `confluence`. Не запускайте его автоматически.
- Исходники демоданных находятся в `.data/` и должны оставаться анонимизированными.
- Не добавляйте в демоданные реальные email, токены, пароли, внутренние URL или исходные идентификаторы.
- Тестовые тексты и названия проектов стилизованы по мотивам «Войны и мира»; сохраняйте этот подход при расширении среза.
- Текущий локальный срез, который отдают API в `ReadOnlyMode=true`, уже целиком тестовый и анонимизированный: он был сгенерирован для этого репозитория, стилизован под «Войну и мир» и не содержит реальных данных. Его можно напрямую переносить в `frontend/src/mocks/data` для demo-сборок без дополнительной анонимизации.

## Frontend demo-режим

- `VITE_DEMO=true` запускает MSW до рендера React. В этом режиме UI не требует бэкенда: обработчики находятся в `frontend/src/mocks/handlers.ts`, а снимки ответов API — в `frontend/src/mocks/data/`.
- Снимки в `frontend/src/mocks/data/` должны сохранять формат реальных ответов API. Не подменяйте их синтетическими структурами без необходимости.
- Данные action items в снимке относятся к фиксированному периоду. Только для отображения таймлайна в demo-режиме они привязываются к абсолютному диапазону дат текущего фильтра; сами ответы MSW не изменяются.
- GitHub Pages публикует demo с `VITE_HASH_ROUTING=true`: ссылки на страницы используют `#/…`, чтобы не получать HTTP 404 от статического хостинга. В локальном и Docker-режимах остаётся обычный BrowserRouter.
- Начальное состояние сайдбара — свёрнутое. Пользовательский выбор хранится в `localStorage` по ключу `sidebar-collapsed`; не сбрасывайте его при открытии страницы.
- Менеджер пакетов фронтенда — pnpm через Corepack. Не возвращайте `package-lock.json` и npm-команды. Dockerfile использует кэш BuildKit для pnpm store — сохраняйте этот паттерн при изменении сборки.

## API и контейнеры

- Интеграционные .NET API запускаются с `ReadOnlyMode=true`: они отдают данные из OpenSearch без учётных данных внешних Jira, GitLab или Confluence.
- В этом режиме сервисы должны явно сообщать в логах, что источники не настроены и API работает только для отдачи данных.
- Локальные адреса: UI — `8081`, Jira — `5001`, Git — `5002`, GitLab — `5003`, Confluence — `5006`, Users State API — `5005`.
